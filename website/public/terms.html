2. What Kiwimake Cloud does

You describe an Android app (or a change to one) in a chat in the Kiwimake phone app. Kiwimake’s AI agent writes the code on a machine we rent for your app, Kiwimake builds it, and the new version arrives on your phone to install. Your app’s code is saved to a private repository on your own GitHub account after every change.

Kiwimake Cloud is new. We work hard to keep it running, but it may sometimes be slow, unavailable or make mistakes.

3. Your account

  • You sign in with Google or with a code we email you. Keep access to that Google account or email address safe: whoever has it can use your Kiwimake account.
  • You must be at least 16 years old to use Kiwimake Cloud.
  • One person, one account. Free credits are given once a month per GitHub account, so making extra accounts to get more free credits is not allowed.
  • Tell us the truth when you sign up and pay, and keep your email address current so we can reach you.

4. GitHub and your code

  • Kiwimake Cloud needs a GitHub account. You connect it by installing the Kiwimake GitHub App. It may create private repositories named anyapp-cloud-… on your account and read and write the code in them. It does not touch your other repositories.
  • Your code lives on GitHub, under GitHub’s own terms. We do not keep a copy of it after a change is done. If you delete a repository, we cannot bring that code back.
  • If you disconnect GitHub or remove the App, cloud changes stop until you connect it again. Your apps and repositories stay as they are.
